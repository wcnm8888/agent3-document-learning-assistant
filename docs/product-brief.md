# 产品简报

## 用户

需要阅读技术教程、论文、产品手册和项目文档，并持续记录学习过程的个人学习者。

## 核心问题

长文档和多文档阅读时，用户很难快速定位事实、确认回答来源、维持连续学习上下文，并管理过时或错误文档。

## 用户价值

用户上传 PDF / Markdown 后，可以：

- 管理、搜索、筛选和切换多个文档；
- 在全部文档或指定文档范围内提问；
- 获得带可追溯来源的回答；
- 区分 PDF 页码与 Markdown 章节、段落和行号；
- 保存学习笔记并回顾会话和学习统计；
- 归档、删除、恢复和重新索引文档。

## 当前产品范围

- 本地单用户 Gradio 知识工作台；
- PDF / Markdown 解析和稳定文档身份；
- `text-embedding-v4` / 1024 维向量索引；
- Qdrant 语义检索和文档范围隔离；
- DeepSeek 兼容接口的检索增强问答；
- SQLite 会话、引用、笔记、学习事件和生命周期状态；
- 桌面、平板和移动端响应式体验；
- 本地健康检查和 SQLite 备份。

## 成功标准

- 回答只基于检索到的文档片段；
- 每条来源可以回到正确文档位置；
- 不同文档和会话不会串用；
- 无结果和失败不会伪装为成功；
- 文档删除有确认、精确 point 删除和失败保护；
- 用户能在常用视口完成上传、索引、问答、核对来源和保存笔记。

## 非目标

- 认证、用户系统和多租户；
- Neo4j、自动知识图谱和复杂 Agent 自主规划；
- 多模态文档；
- 公网生产部署、多实例和生产权限体系；
- 隐式切换 Embedding 模型或重建现有 points。

## 当前限制

- 外部 Embedding / LLM 服务可用性影响索引和回答；
- Gradio 上传进度 404 是已知非阻塞风险；
- 未配置 CI；
- 真实生产故障、恢复、认证和公网安全未演练。
