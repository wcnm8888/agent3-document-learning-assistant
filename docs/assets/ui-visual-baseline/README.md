## 固定运行条件

- 使用 `tests/fixtures/ui_visual_baseline.py`，不得使用生产 `.env`、生产 SQLite 或真实 Qdrant points。
- 浏览器缩放为 100%，设备缩放因子为 1；截图只包含应用视口，不包含浏览器工具栏、Windows 水印或桌面宠物。
- 桌面截图为 1440×900；移动截图为 390×844。
- 字体加载完成、页面稳定且无加载动画后截图。

## 固定状态

### 学习会话完成态

1. 启动夹具并进入“学习会话”。
2. 问答范围选择“全部文档”。
3. 提问：`这份材料的核心章节如何推进？`
4. 确认出现一条用户问题、一条助手回答、一个 PDF 来源和一个 Markdown 来源。
5. 在笔记中输入 `检索链路的四个步骤` 并保存，确认笔记属于当前会话。
6. 截取 1440×900。

### 文档库完成态

1. 启动同一夹具并进入“文档库”。
2. 保持搜索为空、格式和状态为全部、更新时间降序。
3. 选择 `Happy-LLM-0727.pdf`，右侧显示完整 `document_id`、hash、统计和生命周期入口。
4. 截取 1440×900。

### 移动上下文面板

1. 先按“学习会话完成态”生成回答和来源。
2. 切换到 390×844，打开上下文底部面板并选中“来源”。
3. 确认 PDF 页码与 Markdown 章节/段落/行号仍可理解。
4. 截取 390×844。

## 验收边界

后续可以因 Gradio DOM 限制做等效实现，但必须保持区域层级、首屏 Composer、主要尺寸密度、主色语义和三类页面状态。任何阶段只有在上述固定状态完成同图对照后，才能称为视觉验收通过。
