## 顶部导航规格

来源节点：`1560:1444`。

- 高度：76px。
- 上内边距：20px。
- 下内边距：16px。
- 左右内边距：40px。
- 背景：`rgba(0, 0, 0, 0.9)`。
- 背景效果：10px backdrop blur。
- 品牌组间距：14px。
- 品牌图标容器：30px。
- 品牌文字：26px，40px 行高，白色，粗体。
- 右侧操作间距：20px。
- 搜索操作区：40px 容器，内部图标约 24px。
- 设置操作区：40px 容器，圆角 20px，内部图标约 26px。

### 产品化改造

- 不复制模板中的 Cosmo 名称和 Logo。
- 产品标题改为“文档学习助手”或负责人确认的品牌名称。
- 右侧操作改为当前范围、状态、帮助或设置；不引入认证或无关账号行为。
- 顶部导航只承载全局信息，不承载文档库的全部筛选控件。

## 左侧空间导航规格

来源节点：`1560:1459`。

- 导航项宽度：200px。
- 单项高度：42px。
- 单项水平内边距：10px。
- 单项垂直内边距：6px。
- 图标容器：30×30px。
- 图标与文字间距：8px。
- 导航项之间的普通间距：4px；导航分组间距：8px。
- 导航项圆角：16px。
- 导航文字：活动项约 16px；次级项约 14px；20px 行高。
- 活动项文字为白色；非活动项约为 `#A1A1A9`。
- 新建/添加入口使用 `#2F80ED` 文字或图标强调。
- 导航中可以使用右侧 30px 图标容器承载添加或更多操作。

### 产品化映射

| 模板概念 | 产品内容 |
| --- | --- |
| Home | 学习会话或工作台首页 |
| Library | 文档库 |
| 外部资源项 | 不直接照搬，改为当前文档、最近会话或来源复习 |
| Create a task | 上传文档 / 新建会话，具体文案待 UI-R2 确认 |

## 主消息区规格

来源节点：`1239:27621` 内的消息容器 `1239:40293`。

- 内容宽度：680px。
- 内容容器高度：726px。
- 消息纵向间距：8px。
- 同一消息组内气泡间距：4px。
- 内容底部内边距：10px。
- 消息容器采用底部对齐，让最新内容靠近 Composer。
- 用户消息右对齐；助手消息左对齐。
- 用户气泡最大示例宽度：320px。
- 助手长消息示例宽度：350～380px。
- 气泡水平内边距：14px。
- 气泡垂直内边距：10px。
- 文字字号：16px。
- 文字行高：22px。

## 消息气泡规格

| 类型 | 背景 | 文字 | 圆角规则 |
| --- | --- | --- | --- |
| 用户消息 | `#2F80ED` | `#FFFFFF` | 三角方向的单角 4px，其余 16px |
| 助手消息 | `#27282A` | `#FFFFFF` | 三角方向的单角 4px，其余 16px |
| 日期/分组分隔 | `#18181B` | `#717179` | 40px 全胶囊 |
| 发送按钮 | `#FFFFFF` | 深色图标 | 30×30px，20px 圆角 |

### 产品化改造

- 用户消息替换为用户问题文本。
- 助手消息承载回答正文、拒答、引用入口和加载状态。
- 不将 RAG 原始 payload 放进消息气泡；来源进入右侧上下文检查器。
- 加载中使用“正在检索文档”“正在生成回答”等可读状态，不显示技术耗时日志作为主要反馈。

## Composer 输入区规格

来源节点：`1239:48362`。

- 宽度：1440px 页面级容器。
- 主内容内部宽度：680px。
- 高度：约 68px。
- 底部内边距：16px。
- 顶部使用 1px 边界线。
- 背景：`rgba(0, 0, 0, 0.9)`。
- 背景效果：10px backdrop blur。
- 内部水平布局：图标 → 输入文本 → 发送按钮。
- 内部元素间距：10px。
- 输入文字：16px，24px 行高，`#A1A1A9`。
- 图标区域：30px 宽，36px 高；内部图标约 20px。
- 发送按钮：30×30px，圆形，内部箭头图标约 18px。

### 产品化改造

- 将现有大块 `gr.Textbox` 视觉上转化为底部 Composer，但保留现有输入绑定和问答行为。
- 文档范围选择放在 Composer 上方的上下文条或其左侧附属区域，不和文档搜索筛选混淆。
- 问答按钮、清空输入和禁用状态必须有清晰文字或可访问标签。

## 颜色规格

模板 design context 显式返回的颜色：

| Token | 值 | 用途 |
| --- | --- | --- |
| Black | `#000000` | 页面背景 |
| Zinc/900 | `#18181B` | 日期分隔、深层表面 |
| Zinc/800 | `#27282A` | 助手气泡、深层组件 |
| Zinc/500 | `#717179` | 弱文字、日期分隔文字 |
| Zinc/400 | `#A1A1A9` | 次要文字、输入提示 |
| White | `#FFFFFF` | 主文字、发送按钮背景 |
| Color App | `#2F80ED` | 主交互、用户气泡、添加入口 |

文档学习助手可以继续使用现有的状态颜色：成功绿色、警告橙色、错误红色；但这些颜色不应替代模板的主交互蓝色，也不能只用颜色表达状态。

## 字体规格与项目适配

- 模板使用 `Satoshi:Medium` 和 `Satoshi:Bold`。
- 模板正文约 16px，行高 22～24px。
- 模板次要文字约 14px，行高 20px。
- 模板日期/辅助文字约 12px，行高 20px，并使用大写/分组标签风格。
- 项目不直接引入模板的 Satoshi 字体资源。
- 项目继续使用系统中文字体回退：`Microsoft YaHei`、`PingFang SC`、`Noto Sans CJK SC`、sans-serif。
- UI-R2 需要确认中文标题、正文、表格、来源片段和代码/ID 的字号层级。

## 间距和圆角规格

模板可直接观察到的规格：

- 4px：同组消息气泡间距。
- 6px：导航项垂直内边距、日期标签垂直内边距。
- 8px：导航项间距、消息组间距、图标与文字间距的基础倍数。
- 10px：Composer 内部元素间距、气泡水平内边距的一部分。
- 12px：日期标签水平内边距。
- 14px：消息气泡水平内边距。
- 16px：消息气泡垂直内边距、Composer 底部内边距、顶部导航底部内边距。
- 20px：顶部导航上内边距、右侧操作间距、主要圆角数值。
- 30px：图标容器、发送按钮和浮动操作按钮尺寸。
- 40px：顶部操作容器、日期标签全胶囊圆角。
- 76px：顶部导航高度。
- 680px：中央阅读和输入内容宽度。

## 组件映射建议

| 模板组件 | 当前 Gradio 组件 | UI-R2 建议 |
| --- | --- | --- |
| Top Menu | `gr.Markdown` + `gr.Row` | 保留 Gradio 外壳，重组为产品标题、范围和全局操作 |
| 左侧资源导航 | 现有文档库 `gr.Column` | 从文档库内容中拆出空间导航层，文档列表进入主工作区 |
| 消息气泡 | `gr.Chatbot` | 保留绑定，使用消息区样式和上下文来源入口重组 |
| Message UI | `gr.Textbox` + 操作按钮 | 视觉上重组为底部 Composer，保留问答事件绑定 |
| 来源上下文 | `gr.JSON` | 改为来源卡片/折叠项，原始 JSON 作为可选详情 |
| 文档列表 | `gr.Dataframe` | 优先设计为可读行项目；若 Gradio 限制无法替换，保留数据绑定并使用包装层和详情区改善可读性 |
| 文档详情 | `gr.JSON` | 改为结构化详情卡，完整 ID/hash/错误信息仍可展开 |
| 笔记 | `gr.Textbox` + `gr.Dataframe` | 设计为编辑卡 + 笔记列表，保持现有保存/更新事件 |

## UI-R2 必须继续确认的项目

1. 文档库是默认入口还是学习会话是默认入口。
2. 文档列表是独立页面、主区 Tab 还是主区内的工作台模式。
3. 文档详情使用右侧抽屉、居中对话框还是主区内联详情。
4. 来源和笔记使用同一右侧检查器的 Tab，还是两个上下堆叠的上下文卡片。
5. 移动端使用底部面板还是全屏抽屉。
6. Gradio `Dataframe` 无法满足设计稿时，允许的最小 UI 包装方式。
