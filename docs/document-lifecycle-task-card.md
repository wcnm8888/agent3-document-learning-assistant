# 文档生命周期管理任务卡

## 目标

为当前单用户、本地知识库增加可审计的归档、删除、恢复和重新索引能力，不改变现有 v4 collection、Embedding 模型或真实 Qdrant points。

## 本轮范围

- 文档归档与取消归档；
- 删除前确认、精确删除对应 Qdrant points、删除后保留 SQLite tombstone；
- 从原始路径重新索引；
- SQLite/Qdrant 一致性校验；
- 笔记、引用、会话历史保留和关联保护；
- Qdrant 失败、SQLite 失败和原始文件缺失时的回滚/恢复路径；
- 全部测试使用临时 SQLite 与临时 Qdrant。

## 非目标

- 不物理删除 SQLite 文档记录；
- 不删除真实生产 points 或重建现有 collection；
- 不引入认证、用户系统、多租户、Neo4j 或公网部署；
- 不提供跨设备回收站或后台异步任务系统。

## 验收口径

1. 归档不删除 points，只让默认文档列表和检索排除该文档；显式恢复后重新可用。
2. 删除必须二次确认；删除后 points 为 0，SQLite 保留 `deleted` tombstone、哈希、原路径和审计事件。
3. 已删除同内容默认仍识别为 tombstone，不静默创建第二条记录；用户只能通过恢复/重新索引显式复活原记录。
4. 笔记、引用、会话历史不因删除级联丢失；删除后不能创建新的该文档笔记关联。
5. 失败时既有 `indexed` 文档不能被错误标记为 `deleted`；跨存储异常必须留下可校验的 `deleting` 或 `inconsistent` 状态。
6. 67 项现有测试保持通过，新增生命周期测试只操作临时存储。
